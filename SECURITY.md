# Security Policy

## Reporting a Vulnerability

MM maintainers take security bugs seriously. We appreciate responsible disclosure and will acknowledge valid reports.

To report a security issue, please use the GitHub Security Advisory ["Report a Vulnerability"](https://github.com/shuo1104/mac_menu/security/advisories/new) tab.

The maintainers will respond with the next steps and may request additional information needed to reproduce or resolve the issue.

Report security bugs in third-party dependencies to the person or team maintaining the package or dependency.
